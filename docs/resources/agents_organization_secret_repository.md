# github_agents_organization_secret_repository (Resource)

Adds a repository to the allow list of a GitHub Agents organization secret.

This resource grants a single repository access to an existing organization secret. You must have write access to an organization secret to use this resource.

This resource is only applicable when `visibility` of the existing organization secret has been set to `selected`.

## Example Usage

```terraform
resource "github_agents_organization_secret" "example" {
  secret_name = "EXAMPLE_SECRET_NAME"
  value       = "example-value"
  visibility  = "selected"
}

resource "github_repository" "example" {
  name       = "example-repo"
  visibility = "public"
}

resource "github_agents_organization_secret_repository" "example" {
  secret_name   = github_agents_organization_secret.example.secret_name
  repository_id = github_repository.example.repo_id
}
```
