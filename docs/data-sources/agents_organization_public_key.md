# github_agents_organization_public_key (Data Source)

Get information on a GitHub Agents organization public key.

Use this data source with the `value_encrypted` argument of the `github_agents_organization_secret` resource. See the [REST API endpoints for agent secrets](https://docs.github.com/rest/agents/secrets#get-an-organization-public-key) for the required token scopes and permissions.

## Example Usage
